Contagious Wealth Bot

A local dashboard that screens stocks for cash-secured-put income and ranks them by return on risk. Suggest-only: it never places a trade.

View on GitHub Setup

What it does

Selling a cash-secured put means getting paid to agree to buy a stock at a lower price. This tool finds stocks worth doing that on, then finds the specific put contract to sell and shows what it pays relative to the cash you would tie up.

1. Trend gateOnly stocks above a rising 30-week moving average (Weinstein Stage 2) survive.
2. Quality checksP/E, free cash flow, EPS beat, debt-to-equity, ROE and revenue growth shown as a checklist.
3. Volatility floorOptions Trading mode drops stocks too calm to pay rich premium.
4. The putThe contract nearest -0.20 delta (kept within 0.20 to 0.30), ranked by RoR%.

RoR% is premium divided by net capital at risk (strike × 100 minus premium), over the contract's actual days to expiration. That is the same convention thinkorswim uses.

Features

  • Universes: S&P 500, Russell 2000 and 3000, or a saved snapshot you generate once and reuse instead of re-screening about 2,600 symbols.
  • Options chains are fetched on demand, per row or for everything shown. A fetch resumes where it stopped and can be cancelled.
  • Hide toggles for far-out contracts, low RoR and rows with no data, plus optional columns such as Short % Float.
  • Paste your own tickers and add them to the current list, or replace it.
  • Your last scan setup is restored when you restart.

Run it

It runs on your machine. Market data comes from Yahoo Finance through yfinance, so no API keys or broker account are needed.

git clone https://github.com/Areax/contagious-wealth-bot.git
cd contagious-wealth-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py web --port 8899

Then open http://127.0.0.1:8899. This page is static; the dashboard itself needs live data and a Python server, so it can't be hosted here.

Limits worth knowing

  • Yahoo's free options data is sometimes thin for small or illiquid stocks, so some rows show "-" even when a broker shows a full chain.
  • Short interest is reported twice a month and is always 1 to 2 weeks old. It does not include borrow cost or utilization.
  • Quotes can be delayed. Check the contract in your broker before acting.
Not financial advice. This is a screening tool for education and research. It does not know your finances, risk tolerance or tax situation, and options can lose more than the premium collected. You make and place every trade yourself.
